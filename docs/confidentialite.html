Politique de confidentialité d'Agenda Google accessible

Dernière mise à jour : 5 novembre 2026.

Agenda Google accessible est un logiciel Windows gratuit de Luc Rasschaert (Exatropic). Il permet de gérer son agenda Google au clavier, avec un lecteur d'écran.

Les données auxquelles le logiciel accède

Avec votre autorisation, donnée sur la page de connexion de Google, le logiciel accède à votre Google Agenda : la liste de vos agendas, leurs rendez-vous, leurs alarmes et leurs réglages de partage. Il n'accède à aucune autre donnée de votre compte Google.

Comment il les utilise

Ces données servent uniquement à faire fonctionner le logiciel pour vous : afficher vos rendez-vous, les créer, les modifier ou les supprimer à votre demande, faire sonner vos alarmes, et gérer le partage de vos agendas quand vous le demandez.

Où elles vont

Le logiciel s'exécute sur votre ordinateur et communique directement avec Google. Il n'existe aucun serveur intermédiaire. L'auteur ne reçoit, ne stocke et ne voit aucune de vos données. Elles ne sont ni vendues, ni partagées, ni transmises à qui que ce soit, ni utilisées pour de la publicité ou pour entraîner des modèles d'intelligence artificielle.

Ce qui est enregistré sur votre ordinateur

Pour éviter de vous reconnecter à chaque fois, le logiciel enregistre un jeton de connexion, chiffré par Windows : seule votre session Windows peut le relire. Il enregistre aussi quelques réglages (agenda affiché, alarmes activées, etc.). Le tout se trouve dans le dossier %APPDATA%\AgendaGoogleAccessible. Vos rendez-vous ne sont pas copiés sur le disque.

Supprimer l'accès

Dans le logiciel, menu Fichier, « Se déconnecter du compte Google » efface le jeton. Vous pouvez aussi retirer l'accès à tout moment depuis la page des autorisations de votre compte Google. Supprimer le dossier %APPDATA%\AgendaGoogleAccessible efface tout ce que le logiciel a enregistré.

Respect des règles de Google

L'utilisation et le transfert des informations reçues des API Google par Agenda Google accessible respectent les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée (« Limited Use »).
