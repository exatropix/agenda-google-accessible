Les raccourcis globaux deviennent un choix.

- Nouveau menu **Préférences**, « Raccourcis clavier » : pour chaque raccourci utilisable partout (afficher l'agenda, dire le prochain rendez-vous, dire ceux du jour, lancer l'agenda depuis le menu Démarrer), une case pour l'activer et deux listes pour choisir les touches.
- Ces raccourcis sont **désactivés par défaut** : ils pouvaient entrer en conflit avec d'autres programmes.
- Une option permet aussi de couper **Ctrl+Flèches** dans la liste des rendez-vous.
- Si Windows refuse une combinaison déjà prise par une autre application, l'agenda le signale.
